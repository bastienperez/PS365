# Get-ExMailboxForwarding

## SYNOPSIS

Get mailbox forwarding configuration

## SYNTAX

```powershell
Get-ExMailboxForwarding [[-Identity] <string[]>]
 [-ForwardingAndForwardingSMTPOnly] [-InboxRulesOnly] [-ExportToExcel]
 [-ExportPath <string>] [-ExchangeOnPremise]
```


## DESCRIPTION

Get mailbox forwarding configuration from ForwardingAddress, ForwardingSMTPAddress and Inbox Rules

## EXAMPLES

### EXAMPLE 1

```powershell
Get-ExMailboxForwarding
```

Returns all mailboxes with forwarding configuration.

### EXAMPLE 2

```powershell
Get-ExMailboxForwarding -Mailboxes "user1@example.com","user2@example.com"
```

Returns forwarding configuration for specified mailboxes.

### EXAMPLE 3

```powershell
Get-ExMailboxForwarding -ForwardingAndForwardingSMTPOnly
```

Returns only mailboxes with ForwardingAddress or ForwardingSMTPAddress set.

### EXAMPLE 4

```powershell
Get-ExMailboxForwarding -InboxRulesOnly
```

Returns only mailboxes with inbox rules that forward emails.

### EXAMPLE 5

```powershell
Get-ExMailboxForwarding -ExportToExcel
```

Exports results to an Excel file.

## NOTES

Which forwarding is applied when several are set (see the Precedence column in the output):
1.
ForwardingAddress: applied first.
If it is set, ForwardingSMTPAddress and inbox rules are ignored.
2.
ForwardingSMTPAddress: used when ForwardingAddress is empty.
If it is set, inbox rules are ignored.
3.
Inbox rules: only used when 1 and 2 are empty (or when DeliverToMailboxAndForward is set to $true).
   See https://support.microsoft.com/en-us/help/3069075

Who can configure forwarding:
- ForwardingAddress and ForwardingSMTPAddress can be set by an administrator (Set-Mailbox) and, depending on the role assignment policy of the mailbox, by the user in OWA (Settings > Mail > Forwarding).
  A user can therefore overwrite a value set by an administrator, and the reverse is true.
- Inbox rules (forward or redirect) can be created by the user in Outlook or OWA.

Whether a forwarding really works to an external address depends on the Remote Domain(s) (AutoForwardEnabled) and on the AutoForwardingMode of the outbound spam policy(ies).
See ForwardingWorks in the output.
