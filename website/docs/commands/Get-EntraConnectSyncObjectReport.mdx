# Get-EntraConnectSyncObjectReport

## SYNOPSIS

Reports the objects of the Microsoft Entra Connect Sync connector spaces: sync rules applied, password sync status and sync or export errors.

## SYNTAX

```powershell
Get-EntraConnectSyncObjectReport [[-ConnectorName] <string[]>]
 [[-DistinguishedName] <string>] [[-ObjectType] <string[]>]
 [[-RunHistoryCount] <int>] [[-Top] <int>] [[-ExportPath] <string>]
 [-ErrorsOnly] [-IncludePasswordSync] [-GroupByErrorType] [-LastRun]
```


## DESCRIPTION

Reads the connector space objects with Get-ADSyncCSObject on the Entra Connect Sync server and returns one row per
object: the sync rules applied, the password sync status when asked, the HasSyncError and HasExportError flags and the error texts.

By default every object of every Active Directory connector is returned.
Use -ErrorsOnly to keep only the objects
in error.
The password sync status is read from the object log (Get-ADSyncCSObjectLog, one call per object, slow
on a large directory) and is collected only with -IncludePasswordSync.

With -GroupByErrorType, the function returns a summary instead: the number of objects per error type, per
connector and per error kind (Synchronization or Export).

With -LastRun, the function returns the run history instead: for each connector, the last run of each run
profile (Delta Import, Delta Synchronization, Export...), as shown in the Operations tab of the Synchronization
Service Manager, with its result, duration, counters and errors.

Must be run on the Entra Connect Sync server (ADSync module) with a member of the ADSyncAdmins group.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-EntraConnectSyncObjectReport -ErrorsOnly
```

Lists every object in synchronization or export error, on all AD connectors.

### EXAMPLE 2

```powershell
Get-EntraConnectSyncObjectReport -ErrorsOnly -GroupByErrorType
```

Shows how many objects fail for each error type.

### EXAMPLE 3

```powershell
Get-EntraConnectSyncObjectReport -DistinguishedName 'CN=John Doe,OU=Users,DC=contoso,DC=com' -IncludePasswordSync
```

Shows the rules applied to one user and its last password sync event.

### EXAMPLE 4

```powershell
Get-EntraConnectSyncObjectReport -ErrorsOnly -ObjectType user -ExportPath 'C:\Temp\SyncErrors.csv'
```

Exports the user objects in error to a CSV file.

### EXAMPLE 5

```powershell
Get-EntraConnectSyncObjectReport -LastRun | Format-Table ConnectorName, RunProfileName, Result, StartDate, DurationSeconds, TotalErrors
```

Shows the last run of each run profile on every connector, AD and Entra ID.

## NOTES

Requires the ADSync module, installed with Microsoft Entra Connect Sync.
The error text of the connector space is returned as is: the ...ErrorType columns hold its first line (for
example permission-issue, attribute-value-must-be-unique), the ...Error columns the full text.
